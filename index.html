Yuvomi Homelab Privacy Policy

Effective date: September 1, 2026

Yuvomi Homelab is a private, personal-use application operated by Jeff Lynn. It connects an authorized Google account to privately operated household automation tools.

Google user data accessed

The application requests access only to Google Calendar and Google Tasks data authorized by the account owner. Depending on an explicit user request, it may list, create, update, or delete calendar events and tasks.

How data is used

Google user data is used only to carry out the account owner's requested calendar and task operations. It is not used for advertising, profiling, credit decisions, or any unrelated purpose.

Storage and security

OAuth client metadata and authorization tokens are stored in the operator's private homelab environment. Tokens are protected by access controls and an encrypted application keyring. Calendar and task content is not sold or used to build an independent commercial dataset.

Sharing

Google user data is not sold, rented, or shared with third parties. Data is transmitted to Google APIs and processed by the private homelab components needed to perform the requested operation.

Retention and deletion

Authorization tokens are retained until the account owner revokes access or removes the application's stored credentials. The account owner can revoke access at any time from the Google Account third-party connections page. Requests to remove stored credentials or related application data may also be filed through the contact link below.

Google API Services User Data Policy

Yuvomi Homelab's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

For privacy questions or deletion requests, open an issue in the policy repository.
